= VMware vCenter 群集的 NetApp Disaster Recovery 先决条件
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
在使用 NetApp Disaster Recovery 之前，请确保您的环境满足 VMware vCenter 集群要求，以便复制和恢复能够正常运行而不会出现兼容性问题。



[[general-prerequisites]]
== 一般先决条件

这些先决条件适用于本地 vCenter 集群和 VMware Cloud for AWS 软件定义数据中心 (SDDC)。

* 查看灾难恢复所需的link:../reference/vcenter-privileges.html["vCenter 权限"]。
* 灾难恢复管理的所有 VMware 群集必须使用 ONTAP 卷来托管您要保护的虚拟机。
* 所有由灾难恢复管理的 VMware 数据存储必须使用以下协议之一：
+
** NFS
** 使用 iSCSI 或 FC 协议的 VMFS


* VMware vSphere 版本 7.0 Update 3 (7.0v3) 或更高版本




[[vmware-cloud-sddc-prerequisites]]
== VMware Cloud SDDC 先决条件

如果使用 VMware Cloud SDDC，则适用以下附加先决条件：

* 在 VMware Cloud Console 中，使用管理员和 NSX Cloud 管理员的服务角色。还可以使用组织所有者作为组织角色。参考 https://docs.aws.amazon.com/fsx/latest/ONTAPGuide/vmware-cloud-ontap.html["将 VMware Cloud Foundations 与 AWS FSx for NetApp ONTAP文档结合使用"^]。
* 将 VMware Cloud SDDC 与 Amazon FSx for NetApp ONTAP 实例链接。请参阅 https://docs.netapp.com/us-en/workload-vmware/connect-sddc-to-fsx.html["将 FSx for ONTAP 文件系统连接到 VMware Cloud on AWS"^]。
