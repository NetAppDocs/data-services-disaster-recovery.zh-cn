= 将 NetApp Disaster Recovery 添加到 Amazon EVS 的控制台帐户
:allow-uri-read: 


[role="lead"]
NetApp Disaster Recovery是一种许可产品，必须先购买才能使用。有多种类型的许可证，并且您可以通过多种方式购买许可证。许可证授权您在特定时间段内保护特定数量的数据。

有关灾难恢复许可证的详细信息，请参见 link:../get-started/dr-licensing.html["设置灾难恢复许可"]。



[[license-types]]
== 许可证类型

有两种主要的许可证类型：

* NetApp 提供 link:../get-started/dr-licensing.html["30天试用许可证"]，您可以使用 ONTAP 和 VMware 资源来评估灾难恢复。此许可证提供 30 天的使用时间，可提供无限量的受保护容量。
* 如果您希望在 30 天试用期后获得灾难恢复保护，请购买生产许可证。此许可证可以通过任何 NetApp 云合作伙伴的市场购买，但对于本指南，我们建议您使用 Amazon AWS Marketplace 购买灾难恢复市场许可证。要了解有关通过 Amazon Marketplace 购买许可证的详细信息，请参阅link:../get-started/dr-licensing.html["通过 AWS Marketplace 订阅"]。




[[size-your-disaster-recovery-capacity-needs]]
== 确定灾难恢复容量需求

在购买许可证之前，您应该了解需要保护多少ONTAP存储容量。使用NetApp ONTAP存储的优势之一是NetApp存储数据的效率很高。  ONTAP卷中存储的所有数据（例如托管虚拟机的 VMware 数据存储区）都是以高效的方式存储的数据。 ONTAP在将数据写入物理存储时默认采用三种存储效率：压缩、重复数据删除和压缩。最终结果是存储效率在 1.5:1 到 4:1 之间，具体取决于所存储的数据类型。事实上， NetApp提供了 https://www.netapp.com/media/79014-ng-937-Efficiency-Guarantee-Customer-Flyer.pdf["存储效率保证"^]对于某些工作负载。

这可以使您受益，因为灾难恢复会在应用所有 ONTAP 存储效率后计算容量以进行许可。例如，假设您已在 vCenter 中配置了一个 100 TB（TiB）的 NFS 数据存储，以托管 100 个要使用该服务进行保护的虚拟机。此外，假设当数据写入 ONTAP 卷时，自动应用的存储效率技术导致这些虚拟机仅消耗 33 TiB（3:1 的存储效率）。灾难恢复只需要获得 33 TiB 的许可，而不是 100 TiB。与其他 DR 解决方案相比，这可以极大地降低您的 DR 解决方案的总拥有成本。

.步骤
. 要确定托管要保护的 VMware 数据存储库的每个卷上消耗的数据量，请通过对每个卷运行ONTAP CLI 命令来确定磁盘容量消耗： `volume show-space -volume < _volume name_ > -vserver < _SVM name_ >` 。
+
例如：

+
[listing]
----
cluster1::> volume show-space
Vserver : vm-nfs-ds1
Volume  : vol0
Feature                                Used      Used%
-----------------------------      --------     ------
User Data                           163.4MB         3%
Filesystem Metadata                   172KB         0%
Inodes                               2.93MB         0%
Snapshot Reserve                    292.9MB         5%
Total Metadata                        185KB         0%
Total Used                          459.4MB         8%
Total Physical Used                 166.4MB         3%

----
. 注意每个卷的“总物理使用量”值。这是NetApp Disaster Recovery需要保护的数据量，也是您将用来确定需要许可多少容量的值。
