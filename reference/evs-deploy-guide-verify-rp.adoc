= 验证NetApp Disaster Recovery中一切正常
:allow-uri-read: 


[role="lead"]
在 NetApp Disaster Recovery 中添加复制计划后，请验证该计划处于 *Healthy* 状态，然后继续。

图：复制计划页面image:evs-replication-plan-post-create.png["复制计划页面"]

NetApp Disaster Recovery 会运行一系列测试，以验证所有组件（包括 ONTAP 集群、vCenter 集群和虚拟机）都可访问并准备好进行保护。这称为合规性检查，并定期运行。

复制计划页面显示以下信息：

* 上次合规性检查的状态
* 复制计划的复制状态
* 受保护（源）站点的名称
* 复制计划保护的资源组列表
* 故障转移（目标）站点的名称
